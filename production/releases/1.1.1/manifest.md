# Echo-String: Genesis 1.1.1 发布清单

发布日期：2026-07-26

版本主题：Interface Composition

## 界面重构

- 修复带 `mode` 参数的真实试玩页面被误判成回归页面的问题。
- 事件日志、反思与试玩指标恢复为按需打开的侧边抽屉。
- 移除主场景、侧栏和对象区的固定空白高度。
- 桌面布局调整为紧凑三栏游戏台，扩大主场景的视觉优先级。
- 长期纪行压缩为状态命令栏，永久铭文改为按需展开。
- 重绘亮色层级：背景、工作台、卡片和反馈区使用不同明度与边界。
- 底部自动化审计在回归环境中压缩展示，不再形成第二套主界面。
- 大屏最大内容宽度提升到 1760px，并重新校准 1320 / 1080 / 860 / 520 断点。

## 验收标准

- 普通 `?mode=expedition` 页面不得带有 `regression-mode`。
- 普通游戏首屏不展示事件与试玩指标抽屉。
- 1440px 桌面首屏同时展示目标、动作与场景对象。
- 390px 手机首屏出现第一个场景对象，且无横向溢出。
- 手机远征状态栏不得把第一个场景对象完全推出首屏。
- 地图、日志、设置、主题、简繁、四模式、铭文、检查点、分享和重开均通过真实浏览器控制回归。
- 引导、探索和远征真实点击路径全部通过。
- 数据、UI 契约、长期成长、失败路径和视觉烟雾测试全部通过。
