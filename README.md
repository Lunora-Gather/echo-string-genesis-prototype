# 语弦生态：创世纪

**断句庭院 · Echo-String: Genesis 1.1.2**

一款七章的网页语义解谜游戏。调查庭院，取下刻在器物上的词，再把它写到别处。石头可以变轻，机关可以沉下，同一个词带进下一章也可能打开另一条路。

[在线试玩](https://lunora-gather.github.io/echo-string-genesis-prototype/)

## 开始玩

1. 进入庭院，点场景里的标记，选「扫描」查看对象的词缀和槽位。
2. 用原墨取词，再从词库选词写入另一个对象。手机可以直接点场景下方的「词库」打开调查面板。
3. 达成目标后，从词库选一个词带入下一章，也可以空手前往。
4. 在「远征与铭文」开启远征。每轮有不同的规则组合，操作会积累威胁。完成远征可获得回声残片，用来升级原墨容量、词库容量或稳定度相关铭文。

初次试玩可用「引导」，想自己推断解法可切换「探索」。「远征」加入威胁和稳定度，「沙盒」提供练习和调试工具。章名旁的模式按钮可以打开设置。

进度和长期档案保存在当前浏览器中。简繁体随存档保存，主题使用独立偏好。需要回到本区入口时，可在「本轮操作」中使用「检查点」。

## 1.1.2 更新

- **场景与调查**。章名和目标融入七章场景。桌面在右侧集中调查、取词和反馈，手机使用底部面板。石门开启后会更新画面。
- **跨区携词**。出发前显示下一章和选中的词。地图推进、检查点和刷新会保留相应的推进或携词状态。
- **机关与战斗**。封文大门支持解封和破门，机关庭支持搬石和直接改写。战斗显示来势与破绽，残章守卫逐层显示护文进度。
- **选择与恢复**。本轮操作、关卡笔记和远征档案按需展开。沿用现有存档格式，保留旧档恢复和多标签页变更提示。

## 本地运行

项目无需构建。安装 Node.js 后，在仓库根目录启动本地预览。

```sh
node prototype/server.mjs 4174
```

[打开本地试玩](http://127.0.0.1:4174/index.html)

## 验证与部署

```sh
npm test
```

以上命令覆盖通关、跨区携词、战斗和存档恢复，也检查场景图片、页面资源和版本是否一致。

浏览器回归使用 macOS 自带的 Safari。在 Safari 开发者设置中开启「允许远程自动化」，保持本地预览运行，再执行以下命令。报告和截图写入 `artifacts/browser/`。

```sh
npm ci
npm run test:browser
```

推送 `prototype/` 或部署工作流的改动到 `main` 后，GitHub Actions 会运行回归，将静态客户端发布到 GitHub Pages。工作流可以在 Actions 页面手动运行。 [部署工作流](./.github/workflows/deploy-pages.yml)
